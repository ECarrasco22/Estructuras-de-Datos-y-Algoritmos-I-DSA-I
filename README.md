# Data Structures and Algorithms I

Academic repository for the **Data Structures and Algorithms I** course. This repository contains programming exercises, laboratory assignments, implementations, and supporting documentation developed throughout the course.

The main goal is to organize and document the concepts, practical exercises, and implementations covered during the learning process.

## 📂 Repository Structure

```text
Data Structures I/
│
├── PDFs Documentos/
│   └── Course materials and supporting documentation
│
├── Teoría/
│   └── Exercises and examples developed during classes
│
└── Laboratorio/
    └── Laboratory assignments and practical exercises
```

## 📚 Topics Covered

The repository includes implementations and exercises related to the following topics:

- Stacks
- Queues
- Linked Lists
- Data structure operations and implementations
- Problem-solving exercises

Additional topics and implementations may be added as the course progresses.

## 🛠️ Technologies and Tools

- **Programming Language:** C++
- **IDE:** Microsoft Visual Studio
- **Version Control:** Git
- **Repository Hosting:** GitHub

## Purpose

This repository serves as an academic record of the work completed throughout the course. It provides an organized space to store programming exercises, laboratory assignments, and learning materials while tracking progress in understanding and implementing fundamental data structures.
